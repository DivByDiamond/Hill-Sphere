# Смешанные зоны полей

Что чувствует тело там, где перекрываются поля двух и более ядер, и что из этого рисуют очки.
Код: `common/.../field/resolve/GravityResolver` (физика), `field/view/BoundaryProfile`, `BoundaryGrid`,
`BoundaryMesh` (поверхность раздела), `FieldProbe.seam` (близость к ней). Тесты: `MixedFieldsTest`,
`BoundaryProfileTest`, `BoundaryMeshTest`, `FieldProbeTest`.

## Одно ядро (не меняется)

```
fade(x) = 1 при x ≤ 0.6;  1 − smoothstep(0.6, 1, x) при 0.6 < x < 1;  0 при x ≥ 1      (x = d / R)
тяга    p = g · fade                          g — сила ядра в g, d — расстояние до ядра
d̂       к ядру (притяжение), от ядра (отталкивание)
итог    направление = slerp(низ_ванилы, d̂, fade),  сила = lerp(1, g, fade)
```

## Несколько ядер

Невесомость в выборе не участвует (она только ослабляет итог). Из остальных ядер побеждает то, у кого
в точке самая большая тяга `p_max`. Остальные подмешиваются с весом, который падает до нуля, когда
победитель сильнее в `blendEnd` раз (по умолчанию 1.25):

```
S_i = smoothstep(blendStart, blendEnd, p_max / p_i)        (1.0 … 1.25)
q_i = (1 − S_i) / (1 + S_i)                                 у победителя q = 1
m   = Σ q_i · d̂_i / Σ q_i                                   средний вектор направлений, |m| ≤ 1
g   = Σ q_i · g_i / Σ q_i,   f = Σ q_i · fade_i / Σ q_i
полный  = slerp(низ_ванилы, m / |m|, f), сила lerp(1, g, f)
итог    = |m| · полный + (1 − |m|) · (1 − f) · низ_ванилы   (как векторы)
```

Для двух ядер вес победителя `q₁ / (q₁ + q₂) = 0.5 + 0.5 · S` — то же, что было раньше. `|m|` — «согласие»:
1, когда тяги смотрят в одну сторону, 0, когда они противоположны и равны. При `|m| = 1` формула совпадает
с прежней; при `|m| → 0` от поля ядер ничего не остаётся, только доля ванили на краю `(1 − f)`.

**Поверхность раздела** двух ядер — там, где их тяги равны (`p_a = p_b`, вес 0.5/0.5). Переходя её,
«низ» поворачивается на угол φ между `d̂_a` и `d̂_b`; сила на ней `g · cos(φ/2)` (на плато).

## Два притягивающих

- Раздел пересекает отрезок между ядрами; при равных силах и радиусах это плоскость посередине.
  Сильное ядро отодвигает раздел от себя к слабому. Большое слабое поле вокруг маленького
  сильного — раздел замкнут вокруг маленького (на оси за маленьким ядром тяги согласны: φ ≈ 0).
- На оси между ядрами тяги противоположны: точка равновесия, невесомость. Где равные плато
  перекрываются, тяги равны на всём отрезке оси в перекрытии — невесомость на всём отрезке.
- Рядом с осью сила плавно растёт от нуля: на высоте h над серединой (ядра на ±a)
  `сила = g · h / √(a² + h²)`, направление — к оси. Пример: ядра 0 и 10, точка (5, 3): 0.514 g к оси;
  (5, 0.1): 0.02 g.
- Тело между ними падает к оси и зависает около неё; «низ» меняет кадр, переходя раздел.

## Притягивающее + отталкивающее

- Между ядрами обе тяги смотрят к притягивающему (`φ = 0`): ничего не гасится, ничего не поворачивается.
  Раздел равных тяг там есть, но он незаметен: при равных силах сила там просто `g`, к притягивающему.
- Снаружи от ядер на оси тяги противоположны. Если одно ядро заметно сильнее, за более слабым ядром
  есть **нейтральная точка**: `g_a · fade_a = g_b · fade_b`. Пример: притяжение 2 g в 0, отталкивание
  1 g в 10, радиусы 16: `2 · fade(x/16) = 1` → `fade = 0.5` → x = 0.8 · 16 = 12.8. Там остаётся только
  доля ванили `1 − f = 0.25 g` вниз; по обе стороны точки тяга вдоль оси в разные стороны.
- При равных силах и радиусах нейтральной точки внутри полей нет: за отталкивающим оно сильнее,
  за притягивающим сильнее притягивающее. Раздел — плоскость посередине; на ней сила
  `g · a / √(a² + h²)` и направление вдоль оси к притягивающему.
- Тело между ними: падает к притягивающему. Вокруг: внутри раздела вокруг сильного — к нему или от
  него по его знаку; переходя раздел, «низ» поворачивается на φ, на оси снаружи — через ноль.

## Три и более ядер

Учитываются все ядра, чья тяга не меньше `p_max / 1.25`; с этими весами нет рывка, когда второе по силе ядро
сменяется третьим. Раздел пары `a, b` существует только там, где ни одно другое ядро не тянет сильнее их:
там решатель следует третьему ядру.

## Что было раньше (до правки)

- Смешивались только два самых сильных ядра, направление — `slerp` по дуге, сила `lerp(g₂, g₁, w)`,
  гашение (`· |2w − 1|`) только для почти точно противоположных (угол больше 178.2°).
- Ядра 0 и 10, по 1 g, радиус 16: на оси между ними сила 0, а в 0.1 блока от оси — полная 1 g к оси.
  Рывок от 0 до 1 g на волосок от оси; направление в нулевой силе — произвольный бок (`(0, 0, 1)`).
- Противоположные тяги в зоне смешивания (за отталкивающим ядром, у нейтральной точки) поворачивали
  «низ» в произвольный бок (ось z) через фиксированный перпендикуляр `slerp`: например, притяжение и
  отталкивание по 1 g в 0 и 10, точка (11, 0): направление (0.80, −0.04, −0.60).
- Когда второе по силе ядро сменялось третьим, сила и направление прыгали.
- Очки рисовали раздел по первому корню на оси для каждого кольца, без учёта знака (для
  притяжения + отталкивания — посередине, где ничего не происходит), без третьих ядер; кольца обрывались
  на первом пропуске; в произвольно повёрнутом «низу» у оси сканер граней видел «развернёт» — белое пятно.

## Что рисуют очки

- `BoundaryProfile`: контур `p_a − p_b = 0` в полуплоскости (вдоль оси, от оси) сеткой (marching squares),
  точки пересечения уточняются делением пополам; при равных плато побеждает ближнее ядро, контур —
  плоскость посередине. Вес точки `sin²(φ/2) · (fade_a + fade_b) / 2`: 1 там, где тяги противоположны,
  0 там, где они согласны или поля сошли на нет.
- `BoundaryMesh`: кольца вокруг оси в точках, где контур пересекает ряды сетки, и рёбра по контуру; вес 0 там,
  где третье ядро сильнее пары. `ShellLayer` рисует яркость конца линии `√вес`: бледным для двух полей одного
  знака, смесью бирюзового и янтарного — для притяжения и отталкивания.
- `FieldProbe.seam = q` второго по силе ядра (1 на разделе, 0 там, где одно ядро явно сильнее). Бледная
  заливка «развернёт» у раздела ослабляется до 15 %, чтобы не налезать на кольца; грани, где сила меньше
  0.1 g (тяги почти погасили друг друга), не заливаются вовсе.
